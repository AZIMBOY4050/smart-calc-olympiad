#  SmartCalc Pro

Современный веб-калькулятор для решения математических и алгебраических задач с визуализацией графиков. Проект разработан с акцентом на высокую скорость работы и премиальный UI/UX.

🔗 **[Попробовать онлайн (Render)](https://smart-calc-uz.onrender.com)**

## Возможности

* **Квадратные уравнения** — точный расчет корней и интерактивное построение параболы.
* **Линейные уравнения** — быстрое нахождение решения и визуализация прямой.
* **Системы уравнений** — решение систем линейных уравнений с двумя неизвестными.
* **Арифметические прогрессии** — нахождение n-го члена и суммы прогрессии.
* **Геометрия** — базовые геометрические вычисления.
* **Премиальный UI/UX** — адаптивный дизайн, темная тема, горизонтальное свайп-меню для мобильных устройств.

## Стек технологий

* **Backend:** Python 3, FastAPI, Uvicorn
* **Frontend:** HTML5, CSS3, JavaScript (ES6), Chart.js (для отрисовки графиков)
* **Архитектура:** AI Vibe Coding
* **Деплой:** Render (CI/CD через GitHub)
